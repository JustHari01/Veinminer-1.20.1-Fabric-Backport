This is an unofficial community backport of the Veinminer core from upstream version 2.11.2 for Minecraft 1.21.1 to Minecraft 1.20.1 Fabric.

Veinminer lets players mine a connected vein of blocks with one mining action. Server owners can configure the eligible block groups and gameplay rules with Veinminer's existing settings and commands.

**Requirements:** Minecraft 1.20.1, Fabric Loader 0.19.0 or later, Fabric API, and Fabric Language Kotlin.

Install this core on the server. For singleplayer, install it in the client instance as well, because the integrated server runs there. The separate Hotkey add-on adds client controls and requires this matching core.
