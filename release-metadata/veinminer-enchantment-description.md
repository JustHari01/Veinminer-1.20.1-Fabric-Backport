# Veinminer Enchantment 1.20.1 Fabric Backport (UNOFFICIAL)

This is an unofficial community backport of the Veinminer Enchantment add-on from upstream version 2.11.2 for Minecraft 1.21.1 to Minecraft 1.20.1 Fabric.

Veinmine adds a rare enchantment that gates Veinminer: while this add-on is installed, vein mining only works when the main-hand tool has the Veinmine enchantment. Veinminer's block groups and server settings continue to apply.

## Requirements

- Minecraft 1.20.1
- Fabric Loader
- Fabric API
- Fabric Language Kotlin
- The matching [Veinminer 1.20.1 Fabric Backport](https://modrinth.com/mod/veinminer-1201-fabric-backport)

## Configuration

On first launch, the add-on creates `config/veinminer_enchantment.json`. It preserves the upstream setting names and defaults: `weight` (1), `min_cost` (15), `max_cost` (65), and `anvil_cost` (7). These control how often Veinmine appears, its enchanting-table level range, and its anvil cost.
