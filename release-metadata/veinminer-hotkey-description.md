This is an unofficial community backport of the Veinminer Hotkey client add-on from upstream version 2.11.2 for Minecraft 1.21.1 to Minecraft 1.20.1 Fabric.

The add-on provides a hold or toggle hotkey for vein mining, a mining preview, and controls for selecting and editing patterns. The default hold key depends on the keyboard layout; key bindings can be changed in Minecraft's Controls menu. While the add-on is installed, vein mining requires its hotkey to be active and still follows the server's block rules and settings.

**Requirements:** Minecraft 1.20.1, Fabric Loader 0.19.0 or later, Fabric API, Fabric Language Kotlin, and the matching Veinminer 1.20.1 Fabric Backport core.

This add-on is client-only. Install the core on the server and install both the core and Hotkey add-on in each client instance that uses the Hotkey features. For singleplayer, install both in the client instance.
